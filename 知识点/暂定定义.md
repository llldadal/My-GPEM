# 暂定定义
暂定定义是一个 C 语言概念，通常指文件作用域中没有初始化器、也没有存储类说明符（或只有 `static`）的对象声明，例如：
```c
int a;
```
这种未初始化变量的定义

在同一个文件里，暂定定义可以出现多次
- 如果最后有正式定义出现，则舍弃所有的暂定定义，按正式定义来编译
- 如果同一翻译单元中没有出现正式定义，则这些暂定定义最终等同于一个以 `0` 初始化的定义。在采用 ELF 的常见工具链中，GCC 默认的 `-fno-common` 通常会把它放入 `.bss` 节

## 与正式定义的区别
正式定义，如:
```c
int a = 0;

static int a = 100;
```
等已经初始化的变量定义叫做正式定义

在编译时，它们通常会根据链接属性成为 GLOBAL 或 LOCAL 符号。

## 一些历史原因导致的误解
在作者所学习的csapp教材中，有类似以下的描述：
> 未初始化的全局变量为弱符号
> 
> 类似 `int a;` 这样的暂定定义符号通常标记为 COMMON

这里的 COMMON 不是 WEAK 绑定。它是传统工具链为未初始化全局变量采用的一种公共块表示，使链接器可以合并不同目标文件中的同名公共符号。

**但是，这是旧版 GCC 的默认行为了，GCC 10 起默认使用 `-fno-common`！！！**

现代 GCC 默认不再把这类暂定定义生成为 COMMON 符号。因此，如果多个翻译单元都写了同名的 `int a;`，通常会出现多重定义链接错误。

要恢复早期编译器的行为（按道理是不推荐这样干的），可以使用参数：
```bash
-fcommon
```
