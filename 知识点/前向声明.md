# 前向声明
前向声明即：先告诉编译器“这个名字和类型确实存在”，之后再给出它的完整定义

示例：

```c++
#include <iostream>

void sayHello();  // 前向声明

void greet()
{
    sayHello();   // 现在编译器知道它是一个函数
}

void sayHello()   // 完整定义
{
    std::cout << "Hello\n";
}
```

当然，类和结构体也能进行前向声明，但是前向声明产生的是不完整的类型

不完整的类型可以：
- 声明指针
- 声明引用
- 以指针和引用的方式传参

不可以：
- 实例化
- 进行任何需要类型内部结构信息的操作（如访问成员）

否则编译器会报错：[使用不完整的类型](../构建期错误/编译时错误/使用不完整的对象.md)

## 使用场景
假设存在两个类：
```c++
class FileInfo
{
public:
    SearchEngine* engine;
};
```
```c++
class SearchEngine
{
public:
    FileInfo* currentFile;
};
```
它们互相引用。如果两个头文件直接互相包含，就可能形成循环包含（当然，这里过不了编译的，因为没有包含）

那么在头文件中可以使用前向声明
```c++
// fileinfo.h
#pragma once

class SearchEngine;  // 前向声明

class FileInfo
{
public:
    SearchEngine* engine;
};
```
```c++
//search_engine.h
#pragma once

class FileInfo;  // 前向声明

class SearchEngine
{
public:
    FileInfo* currentFile;
};
```
这样可以解除两个头文件之间不必要的循环包含，并让编译器在只需要指针或引用的地方知道类型名称。需要访问成员、按值传递对象或销毁某些对象时，仍应在对应的 `.cpp` 文件中包含提供完整类定义的头文件。

`extern` 声明和类的前向声明都能做到“先声明、后定义”，但它们适用的实体不同：变量和函数可以使用 `extern` 声明，类、结构体和枚举则使用对应的前向声明语法。
