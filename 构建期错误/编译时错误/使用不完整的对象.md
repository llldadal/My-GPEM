# 报错：使用不完整的对象

## 问题代码示例
header.h
```c++
#pragma once
struct MyClass;
bool Fun(MyClass myclass);
```
header.cpp
```c++
#include"header.h"
struct MyClass {
	int a = 0;
};
bool Fun(MyClass myclass) {
	if (myclass.a == 0) {
		return false;
	}
	else {
		return true;
	}
}
```
main.cpp
```c++
#include"header.h"
#include<iostream>
MyClass mc1;
int main() {
	std::cout << Fun(mc1) << std::endl;
}
```

## 报错提示（类似于）
```shell
E:\vsprojects\Project7\main.cpp(3,9): error C2079: “mc1”使用未定义的 struct“MyClass”
```

## 报错分析及原因
既然报错提示告诉我们：“mc1”使用未定义的 struct“MyClass”，那问题显然出现在MyClass这个结构体上（没有被定义）

然而，我明明不是在header.h中声明，并且在header.cpp中定义了么，#include也不存在问题呀？为什么编译器找不到MyClass的定义呢？

这涉及到c/c++语言编译和预处理的问题，具体见知识点：

[预处理以及编译](/知识点/预处理和编译.md)

具体到本问题而言，主要是预处理展开header.h后并没有将MyClass的定义加入main.i（因为header.h里面只有声明，没有定义）

可将main.i的内容简单理解如下：

main.i
```c++
/*<iostream>代码*/
struct MyClass;
bool Fun(MyClass myclass);

MyClass mc1;
int main() {
	std::cout << Fun(mc1) << std::endl;
}
```
而编译器在编译到
```c++
MyClass mc1;
```
这一行时，需要为该结构体分配空间。此时还未到链接阶段，所以编译器看不到header.cpp里的定义，故而产生未定义错误

注：在作者遇到此问题时，IDE显示“禁止使用不完整对象”，两者指代同一个问题

## 排查方法
编译器固定报错：
```shell
error C2079： ...使用未定义的...
```
首先确认是未定义问题和什么结构体未定义，随后看此结构体定义是否位于.cpp文件中，若是，证明是此问题

## 解决方法
将结构体的定义写在.h文件中

header.h
```c++
#pragma once
struct MyClass{
	int a
};
```

## 额外补充
类似于：

main.cpp
```c++
#include"header.h"
#include<iostream>
MyClass mc1;
int main() {
	std::cout << Fun(mc1) << std::endl;
}
```
中 MyClass mc1 的这种写法，工程里叫[前向声明](/知识点/前向声明.md)，感兴趣可以了解
