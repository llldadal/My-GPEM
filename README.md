# 草履虫也能看得懂的程序报错指南 目录

如你所见，这些文件是一份（易于理解的？）指南，记录了作者自开篇以来遇到的大部分程序错误的成因和解决、排查办法

## 目录结构
```text
草履虫也能看得懂的程序报错指南
├─小工具
│  └─images
├─构建期错误
│  ├─编译时错误
│  └─链接时错误
├─知识点
└─运行期错误
    ├─加载时错误
    └─运行时错误
```
文件说明：

- 小工具：包含一些作者学到的工具使用方法的总结教学，如Git、MarkDown等
- 知识点：需要了解的一些计算机知识
- 各种错误：错误的排查和解决办法的分类收录
- 其他文件（如images）:使得本MarkDown能正常运行的资源文件
