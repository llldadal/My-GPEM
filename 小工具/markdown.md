# Markdown 标记语言编写教程

Markdown 是一种轻量级标记语言。它允许我们用少量符号设置文章格式，再由编辑器或网站将文本渲染成标题、列表、链接、表格等内容。

Markdown 文件通常以 `.md` 作为扩展名，例如 `README.md`。

> 提示：不同平台支持的 Markdown 语法可能略有区别。本文主要介绍通用 Markdown 和常见的 GitHub Flavored Markdown（GFM）语法。

## 1. 标题

在文字前输入 `#` 和一个空格即可创建标题。`#` 的数量代表标题级别，共有六级。

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

实际显示效果：

# 一级标题示例

## 二级标题示例

### 三级标题示例

#### 四级标题示例

##### 五级标题示例

###### 六级标题示例

建议一篇文档只使用一个一级标题，并按照层级顺序组织内容，不要随意跳级。

## 2. 段落与换行

普通文字直接书写即可。段落之间要留一个空行：

```markdown
这是第一段文字。

这是第二段文字。
```

实际显示效果：

这是第一段文字。

这是第二段文字。

如果只按一次回车，部分渲染器仍会把上下两行显示在同一个段落中。需要强制换行时，可以在行尾输入两个空格，或者使用 HTML 的 `<br>` 标签。

## 3. 强调文字

```markdown
*斜体文字*
_斜体文字_

**粗体文字**
__粗体文字__

***粗斜体文字***

~~删除线文字~~
```

显示效果：

*斜体文字*、**粗体文字**、***粗斜体文字***、~~删除线文字~~

为了避免符号与文字混在一起难以识别，中文内容通常推荐使用 `**粗体**` 和 `*斜体*`。

## 4. 列表

### 4.1 无序列表

在每一项前输入 `-`、`*` 或 `+`，并在符号后添加一个空格：

```markdown
- 苹果
- 香蕉
- 橙子
```

实际显示效果：

- 苹果
- 香蕉
- 橙子

建议在同一篇文档中统一使用 `-`。

### 4.2 有序列表

```markdown
1. 打开编辑器
2. 新建 Markdown 文件
3. 输入内容并保存
```

实际显示效果：

1. 打开编辑器
2. 新建 Markdown 文件
3. 输入内容并保存

### 4.3 嵌套列表

子列表通常缩进两个或四个空格：

```markdown
- 前端
  - HTML
  - CSS
- 后端
  - Python
  - Java
```

实际显示效果：

- 前端
  - HTML
  - CSS
- 后端
  - Python
  - Java

### 4.4 任务列表

任务列表常用于记录待办事项：

```markdown
- [x] 创建文件
- [x] 编写标题
- [ ] 检查内容
```

显示效果：

- [x] 创建文件
- [x] 编写标题
- [ ] 检查内容

## 5. 引用

在文字前输入 `>` 和一个空格：

```markdown
> 这是一段引用。
>
> 引用中也可以包含多个段落。
```

实际显示效果：

> 这是一段引用。
>
> 引用中也可以包含多个段落。

引用还可以嵌套：

```markdown
> 第一层引用
>> 第二层引用
```

实际显示效果：

> 第一层引用
>> 第二层引用

## 6. 行内代码与代码块

### 6.1 行内代码

用一对反引号包裹短代码、命令或文件名：

```markdown
使用 `print()` 函数输出内容。
```

显示效果：使用 `print()` 函数输出内容。

### 6.2 代码块

用三对反引号包裹多行代码。开头的反引号后可以注明语言，以获得语法高亮。

````markdown
```python
def greet(name):
    print(f"你好，{name}！")

greet("小明")
```
````

实际显示效果：

```python
def greet(name):
    print(f"你好，{name}！")

greet("小明")
```

常见语言标识包括 `python`、`javascript`、`java`、`html`、`css`、`json`、`bash` 和 `powershell`。

## 7. 链接

### 7.1 普通链接

```markdown
[链接显示文字](https://example.com)
```

实际显示效果：[链接显示文字](https://example.com)

### 7.2 带提示文字的链接

鼠标停留在链接上时可以显示提示：

```markdown
[示例网站](https://example.com "打开示例网站")
```

实际显示效果：[示例网站](https://example.com "打开示例网站")

### 7.3 自动链接

```markdown
<https://example.com>
<name@example.com>
```

实际显示效果：

<https://example.com>

<name@example.com>

## 8. 图片

图片语法与链接类似，只是在最前面多一个感叹号：

```markdown
![图片无法显示时的说明文字](images/example.png)
```

也可以使用网络图片地址：

```markdown
![Markdown 图片示例](images/markdown-example.svg)
```

实际显示效果：

![Markdown 图片示例](images/markdown-example.svg)

建议始终填写方括号中的替代文字，这有利于无障碍阅读，也方便在图片加载失败时了解图片内容。

## 9. 分隔线

单独一行输入三个或更多的 `-`、`*` 或 `_`：

```markdown
---
```

实际显示效果：

---

为避免与其他语法混淆，建议在分隔线前后各留一个空行。

## 10. 表格

使用竖线 `|` 分隔单元格，使用连字符 `-` 分隔表头和表格内容：

```markdown
| 姓名 | 年龄 | 城市 |
| --- | ---: | :---: |
| 小明 | 18 | 北京 |
| 小红 | 20 | 上海 |
```

对齐方式由冒号决定：

- `:---`：左对齐
- `---:`：右对齐
- `:---:`：居中对齐

显示效果：

| 姓名 | 年龄 | 城市 |
| --- | ---: | :---: |
| 小明 | 18 | 北京 |
| 小红 | 20 | 上海 |

表格两侧最外层的竖线通常可以省略，但保留它们会让源文件更容易阅读。

## 11. 转义特殊字符

如果希望 Markdown 符号按普通字符显示，可以在符号前添加反斜杠 `\`：

```markdown
\*这段文字不会变成斜体\*
\# 这行文字不会变成标题
```

实际显示效果：

\*这段文字不会变成斜体\*

\# 这行文字不会变成标题

常见的可转义字符包括：

```text
\  `  *  _  { }  [ ]  ( )  #  +  -  .  !  |
```

## 12. 脚注

部分 Markdown 编辑器支持脚注：

```markdown
Markdown 很适合编写说明文档。[^1]

[^1]: 它的源文件简洁、易读，也便于进行版本管理。
```

实际显示效果：

Markdown 很适合编写说明文档。[^footnote-example]

[^footnote-example]: 它的源文件简洁、易读，也便于进行版本管理。

如果平台不支持脚注，这些标记可能会按普通文字显示。

## 13. 折叠内容

支持 HTML 标签的平台通常可以使用 `<details>` 创建折叠区域：

```html
<details>
<summary>点击查看答案</summary>

这里是折叠起来的内容。

</details>
```

实际显示效果：

<details>
<summary>点击查看答案</summary>

这里是折叠起来的内容。

</details>

## 14. 目录

有些平台支持在文档中输入 `[TOC]` 自动生成目录，但这不是通用语法。更可靠的方法是手动链接到各级标题：

```markdown
- [标题](#标题)
- [列表](#列表)
- [代码块](#行内代码与代码块)
```

实际显示效果（点击后会跳转到本文对应章节）：

- [标题](#1-标题)
- [列表](#4-列表)
- [代码块](#6-行内代码与代码块)

标题链接通常会将英文转成小写、把空格替换为连字符，并去掉部分标点。中文标题链接的具体规则可能因平台而异。

## 15. 一份完整示例

下面是一篇简单的 Markdown 文档源码：

````markdown
# 我的学习记录

## 今日目标

- [x] 学习标题和列表
- [x] 学习链接和图片
- [ ] 写一篇练习文档

## 学习笔记

Markdown 使用起来非常简单。访问 [Markdown Guide](https://www.markdownguide.org/) 可以查看更多资料。

> 每天练习一点，比一次记住所有语法更有效。

下面是一段 Python 代码：

```python
message = "Hello, Markdown!"
print(message)
```

---

**最后更新：** 2026-09-10
````

## 16. 常见问题与建议

### 符号后忘记加空格

标题和列表的标记后通常需要一个空格：

```markdown
# 正确的标题
- 正确的列表项
```

### 段落、列表和代码块挤在一起

不确定是否需要空行时，可以在标题、段落、列表、引用、代码块和表格之间留一个空行。这通常能得到更稳定的渲染效果。

### 中英文标点混用

Markdown 语法符号应使用英文半角字符。例如，应输入英文的 `#`、`*`、`[`、`]`、`(`、`)`，不要使用外观相似的中文全角字符。

### 图片路径无法使用

相对路径以当前 Markdown 文件所在目录为基准。例如，文档旁边有一个 `images` 文件夹时，可以这样引用：

```markdown
![流程图](images/flowchart.png)
```

路径和文件名需要完全一致。在区分大小写的系统中，`Image.png` 和 `image.png` 是两个不同的文件名。

### 先关注结构，再关注样式

Markdown 的优势是简洁。优先使用标题、段落、列表和代码块组织内容；只有在确实需要时，再加入 HTML 标签或平台专属语法。

## 17. 常用语法速查表

| 用途 | 写法 |
| --- | --- |
| 一级标题 | `# 标题` |
| 二级标题 | `## 标题` |
| 粗体 | `**文字**` |
| 斜体 | `*文字*` |
| 删除线 | `~~文字~~` |
| 无序列表 | `- 列表项` |
| 有序列表 | `1. 列表项` |
| 引用 | `> 引用内容` |
| 行内代码 | 一对反引号包裹代码 |
| 链接 | `[文字](网址)` |
| 图片 | `![说明](图片地址)` |
| 分隔线 | `---` |
| 任务项 | `- [ ] 未完成` |

掌握这些基础语法后，就可以使用 Markdown 编写项目说明、学习笔记、博客文章和技术文档了。
